# Security policy

## Reporting a vulnerability

Email **pixellayer7@gmail.com** with a clear description (steps to reproduce, impact, and any suggested fix if you have one).

Please do **not** open a public GitHub issue for an undisclosed security vulnerability.

## Scope

This policy applies to the **project-estimator** repository (the React/Vite calculator and its GitHub Actions workflows).

## Response

We will acknowledge receipt as soon as practical. This is a small project; there is no formal SLA.
